StemGuess

A multiplayer “name that song” game built from song stems, with real-time rounds.

React, TypeScript, Socket.IO, Web Audio, Capacitor, Python, FastAPI, SQLAlchemy, PostgreSQL, Cloudflare R2, Render · Live website · Source code
Show detailsHide details

A multiplayer “name that song” game. Each round loops a short clip built from a song’s stems and shows four titles. Players pick once, and a correct answer scores 10 points at the start of the round, falling to 1 at the buzzer. Halfway through, a player can remove wrong options for a lower score. Hosts choose the song library, filters, game length and room size, and late joiners can spectate. There is also a solo practice mode.

I built the whole stack: a real-time game server in Python, a React client that also builds as an Android app, a song pipeline that splits tracks into stems and stores them in the cloud, and an option to play with your own music, with vocals removed in the browser.

Voice Vault

An audio notes app that transcribes recordings and lets you search every note by text or voice.

JavaScript, Node.js, PostgreSQL, Docker, ElevenLabs Scribe, Vercel, Render · Apps source code
Show detailsHide details

An audio notes app with search across all your notes. Record in the browser or upload audio, and the server turns it into a transcript that labels who spoke each line and tags sounds like laughter or music. You can then search every note by typing or by recording a short voice query, using plain language and time filters such as “yesterday” or “last 3 days”, and click any transcript segment to hear that moment.

I built it end to end: accounts with login, password reset and account deletion, a Node.js API running in Docker, and a PostgreSQL database that holds the notes, audio and search index. Search combines keyword matching with semantic retrieval. The same frontend is packaged for Android, iOS and desktop.
